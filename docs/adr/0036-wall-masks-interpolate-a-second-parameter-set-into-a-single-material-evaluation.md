# Wall masks interpolate a second parameter set into a single material evaluation

**Status:** Accepted

A wall mask is a per-External-edge override, sibling to the wall normal-map override, that blends the wall's primary Sub-material parameters toward a second raw parameter set ("Wall mask blend parameters"); the two sets are interpolated per fragment and evaluated as one material of the primary's technique, so a wall runs its material function once per fragment rather than twice with the results blended. The blend parameters are bounded by the primary Sub-material's Technique schema, and the mask reads one R/G/B/A channel of an ImageResource that may differ from the normal map but shares its single repeat and UVs — one repeat tiles both, the mask's own dimensions get no separate aspect-ratio correction (reconciling them is the author's responsibility), and a mask therefore requires a normal map, whose Image payload owns the shared repeat. Like the normal map, the blend applies to the uncut wall surface only — Chip facets use the primary parameters — and the wall's Emboss preset applies once to the blended material; with no mask, the renderer passes the primary parameters as the blend set and binds a 1×1 zero-value mask texture so the shader contract stays uniform.
